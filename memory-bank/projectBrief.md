# Project Brief

## Purpose

Build a multi-organization IRB automation harness that preserves evidence
provenance and keeps human review in control of institutional rules and website
actions.

## Primary Milestone

KMUH is the first complete organization profile:

- official document sources become a hashed evidence contract;
- workflow and requirements cite reviewed source spans;
- eIRB page controls are mapped after a human logs in;
- no irreversible website operation is automated.

## Success Criteria

- Another organization can compile its own documents without changing KMUH or
  KFSYSCC code.
- Every verified institutional claim resolves to source and span hashes.
- KMUH pages can be inventoried without exposing credentials or case values.
- Documentation and memory clearly distinguish implemented, verified, and
  blocked work.
